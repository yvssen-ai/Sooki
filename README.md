# Sooki

A luxury Egyptian accessories e-commerce landing page. Black & gold, cinematic, mobile-first.

Built with Next.js, Tailwind CSS, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:9002](http://localhost:9002). The main page lives at `src/app/page.tsx`, with sections in `src/components/`.
