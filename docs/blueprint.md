# **App Name**: Curio Coffee Studio

## Core Features:

- Cinematic Immersive Scroll: A single-page smooth scrolling experience using Lenis for fluid motion and Framer Motion for premium component transitions.
- Interactive Sensory Menu: Category-driven menu browser with instant filtering, high-fidelity item photography, and detailed craftsmanship descriptions.
- AI Palate Concierge: An AI-powered tool that provides personalized coffee and food pairing recommendations based on the user's specific flavor preferences and mood.
- Digital Heritage Gallery: An editorial masonry gallery with lightbox support for high-impact coffee preparation and interior visuals.
- Integrated Location Dashboard: A refined visitor panel featuring live operating status, embedded mapping, and utility information like Wi-Fi availability.
- Intelligent Menu Search: A lightning-fast search overlay allowing users to instantly jump to specific beans, matcha variations, or food items.

## Style Guidelines:

- Primary palette uses 'Coffee Brown' (#6F4E37) and 'Accent Bronze' (#A67C52) against a warm cream background (#F5F2EC) for an organic, editorial look.
- The font 'Kanit' (geometric sans-serif) is used for high-impact editorial headings, paired with 'Inter' (grotesque sans-serif) for readable, functional body text.
- Spacious grid-based layout with a maximum content width of 1400px, 120px vertical section spacing, and containers using soft 24px-28px rounded corners.
- Refined motion system featuring clip-path reveals, staggered image fades, and subtle parallax to create a calm yet engaging digital experience.
- Thin-stroke minimalist icons provided by Lucide for navigation and shop utilities, emphasizing clean lines and sophisticated modernism.
